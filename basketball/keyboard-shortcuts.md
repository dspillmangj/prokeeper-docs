# Basketball Keyboard Shortcuts Reference

Master keyboard shortcuts to keep up with the fastest paced games.

---

## Game Clock & Period Hotkeys

| Hotkey | Function | Action |
| :--- | :--- | :--- |
| <kbd>Space</kbd> | **Toggle Clock** | Starts or pauses the official running game clock. |
| <kbd>Enter</kbd> | **Submit Command** | Records the stat in the entry box and refreshes the HUD. |
| <kbd>Esc</kbd> | **Focus Entry Bar** | Returns keyboard focus to the stat entry field from anywhere on screen. |

---

## Action Hotkeys (Syntax Suffixes)

```
========================================================================

[A] ASSIST        [S] STEAL         [K] BLOCK         [W] SWAT
[P] PASS TO       [U] FUMBLE TO     [I] VIOLATION TO
[F] PERS FOUL     [R] OFF FOUL      [T] TECH FOUL     [H] DRAWN FOUL

```

---

## Team Prefixes
* **Home Team**: Suffix with `-` (e.g. `23-X`)
* **Away Team**: Suffix with `=` (e.g. `11=M`)

---

## Substitution Command Format
* Fast sub syntax: `SUB <home|away> <OutJersey>-><InJersey>`
* Example: `SUB home 23->02` subbed #23 out, #02 in.
