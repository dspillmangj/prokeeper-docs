# QR Codes & Game Access Keys

Distribute instant live stats to fans, journalists, and college recruiters in the stands without needing accounts.

---

## 6-Character Access Keys

Every game session is assigned a collision-resistant 6-character access key (e.g. `EAG101`, `VB202`).

* Fans can navigate to the [App](https://app.prokeeper.org) and type the 6-character code into the fast viewer box.
* Direct URL: `https://app.prokeeper.org/live/{access_code}`.

---

## Arena QR Codes

* Game operators can click **Print Program QR Code** on the game dashboard.
* Print the QR code on game day paper programs or display it on the gym ticketing table.
* Fans scan the code with their smartphone camera to instantly launch the live interactive scoreboard on iOS and Android browsers.
