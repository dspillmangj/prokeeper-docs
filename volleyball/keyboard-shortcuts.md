# Volleyball Keyboard Shortcuts & Fast Entry

Fast-paced rally recording with minimal keystrokes.

---

## Command Syntax

$$\text{<Jersey Number>} + \text{<Team Indicator>} + \text{<Action Code>}$$

```
04-K     -> Home #04 recorded a Kill (+1 Home point)
07=A     -> Away #07 served an Ace (+1 Away point)
08-B     -> Home #08 made a Solo Block (+1 Home point)
12-D     -> Home #12 made a Dig
```

---

## Action Hotkey Mappings

| Action Code | Statistical Description | Point Awarded To |
| :---: | :--- | :--- |
| `K` | **Kill** | Same Team (+1 pt) |
| `E` | **Attack Error** | Opponent (+1 pt) |
| `T` | **Attack Attempt** | No point (Ball kept in play) |
| `A` | **Service Ace** | Same Team (+1 pt) |
| `S` | **Service Error** | Opponent (+1 pt) |
| `D` | **Dig** | No point |
| `B` | **Solo Block** | Same Team (+1 pt) |
| `C` | **Block Assist** | Same Team (+1 pt) |
| `Z` | **Set Assist** | No point |
| `H` | **Ball Handling Error (BHE)** | Opponent (+1 pt) |
| `R` | **Reception Error** | Opponent (+1 pt) |
